# Single-Page CV

A starting workspace for the [roadmap.sh Single-Page CV project](https://roadmap.sh/projects/single-page-cv).

## Get started

Edit `index.html` to build your CV. Open the file in a browser to preview it; refresh the page after making changes. No dependencies or build step are needed.

## Project checklist

- [ ] Use semantic HTML to structure the page.
- [ ] Add sections for education, skills, and career history.
- [ ] Add SEO meta tags.
- [ ] Add Open Graph tags for social sharing.
- [ ] Create a favicon and link it in the document head.

The project is HTML-only and should be ready for styling in a future project.
